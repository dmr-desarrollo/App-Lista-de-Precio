# **App Name**: Product Catalog Constructor

## Core Features:

- CSV Data Loading: Asynchronously load and consolidate data from 31 CSV files into a single data structure. The app will handle errors gracefully if any file is inaccessible or corrupted.
- Product Display: Display products in a grid or list format, showing key information (name/description, SKU, price) for each product. Product information will come directly from the loaded CSV data.
- Real-Time Search: Implement a search bar that filters products by name, description, or SKU as the user types. Only matching products will be visible after filtering.
- Category Filtering: Enable users to filter products by category, derived from the CSV filenames. Allows focusing on specific product types quickly.

## Style Guidelines:

- Primary color: Navy blue (#2E5266) to convey trust and professionalism, complementing the product catalog's business context.
- Background color: Light gray (#F0F4F7) to ensure readability and a clean, modern backdrop.
- Accent color: Teal (#4DB6AC) for interactive elements and highlights, providing a contrast that draws attention without being distracting.
- Body and headline font: 'PT Sans' (sans-serif) for a modern look combined with warmth or personality.
- Responsive grid layout to adapt smoothly to various screen sizes.
